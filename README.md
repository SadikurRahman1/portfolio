# পোর্টফোলিও (GitHub থেকে আপডেট করা যায়)

এই ফোল্ডারটা তোমার GitHub রিপোজিটরিতে আপলোড করলেই ওয়েবসাইট রেডি হয়ে যাবে, এবং পরে যেকোনো তথ্য বদলাতে হলে শুধু `data.json` ফাইলটা এডিট করলেই চলবে — কোড ছোঁয়ার দরকার নেই।

## ফোল্ডার স্ট্রাকচার

```
portfolio-repo/
├── index.html      → মূল ওয়েবসাইট (এটা data.json থেকে তথ্য টেনে দেখায়)
├── data.json       → তোমার নাম, ছবি, স্কিল, প্রজেক্ট, CV লিংক — এখানেই এডিট করবে
├── assets/
│   ├── profile.jpg → তোমার ছবি এখানে রাখো (ঠিক এই নামে)
│   └── cv.pdf       → তোমার CV এখানে রাখো (ঠিক এই নামে)
└── README.md
```

## ধাপে ধাপে GitHub Pages-এ পাবলিশ করা

1. GitHub-এ একটা নতুন পাবলিক রিপো বানাও (যেমন `portfolio`)।
2. এই ফোল্ডারের সব ফাইল (index.html, data.json, assets/ ফোল্ডারসহ) রিপোতে আপলোড করো।
3. রিপোর **Settings → Pages**-এ যাও।
4. **Branch: main**, folder: **/(root)** সিলেক্ট করে Save করো।
5. কিছুক্ষণ পর তোমার সাইট লাইভ হবে এই ঠিকানায়:
   `https://<তোমার-github-username>.github.io/<রিপোর-নাম>/`

## পরে আপডেট করার নিয়ম

- **ছবি বদলাতে চাইলে**: নতুন ছবি `assets/profile.jpg` নামে আপলোড করে পুরনোটা রিপ্লেস করো।
- **CV বদলাতে চাইলে**: নতুন PDF `assets/cv.pdf` নামে আপলোড করো।
- **স্কিল/প্রজেক্ট/যোগাযোগের তথ্য বদলাতে চাইলে**: `data.json` ফাইলটা GitHub-এর ওয়েব এডিটরেই (pencil আইকনে ক্লিক করে) খুলে বদলে Commit করো — সাইট নিজে থেকেই আপডেট হয়ে যাবে, কোনো রিডিপ্লয়ের দরকার নেই।

## data.json-এর ভেতরে যা যা আছে

- `profile` → নাম, টাইটেল, লোকেশন, ইমেইল, ছবি, CV, GitHub/LinkedIn/Facebook/Instagram লিংক
- `skills` → টেকনিক্যাল স্কিলের লিস্ট (যত খুশি যোগ/বাদ দিতে পারো)
- `projects` → প্রতিটা প্রজেক্টের নাম, বর্ণনা, লিংক, এবং ট্যাগ

## দ্রষ্টব্য

- `index.html` ফাইলটা সরাসরি ডাবল-ক্লিক করে ব্রাউজারে খুললে `data.json` লোড নাও হতে পারে (ব্রাউজার সিকিউরিটির কারণে) — GitHub Pages-এ পাবলিশ করলে এই সমস্যা হবে না।
- এই ভার্সনটা হালকা রাখা হয়েছে (শুধু প্রোফাইল, স্কিল, প্রজেক্ট ডাইনামিক) — Experience/Education/Services-সহ পুরো ডিজাইনের ভার্সনটা চাইলে বলো, সেটাও একইভাবে data.json থেকে টানার ব্যবস্থা করে দিতে পারি।
